05 常见问题

关于平台的几个问题

开始之前，先看看这些常见疑问。

支持哪些编程语言？ +

当前版本专注于 C++（基于 g++，支持 C++17 标准）。这是出于教学场景与评测一致性的考虑 —— 单一语言能让评测沙盒、编译参数与判题逻辑更可预期。

我的代码与提交记录会被保存吗？ +

当前阶段不持久化用户提交的代码与提交记录。题目、测试用例与账号信息存储在 MySQL 中，但运行历史与代码本身仅保留在浏览器会话内。后续计划接入 Redis / 数据库做提交历史回看。

系统如何保证评测安全？ +

每次提交都在独立子进程中运行，配合 setrlimit 设置 CPU 时间、内存与输出体积上限。这是一种进程级隔离方案，对教学/训练规模足够安全；如需更高强度，可后续升级为容器级隔离。

评测结果有哪几种？ +

系统会逐用例比对实际输出与期望输出，给出以下几种判题结果：

  • AC Accepted — 答案正确
  • WA Wrong Answer — 答案错误
  • TLE Time Limit Exceeded — 运行超时
  • RE Runtime Error — 运行时错误
  • CE Compile Error — 编译失败
如何成为管理员？ +

普通用户注册即可登录使用。管理员账号需由已有管理员在管理后台手动创建，或由运维同学直接在 MySQL 中将 users.role 字段更新为 'admin'，之后便可访问 /admin.html 进行题目管理。

是否提供 API 接入？ +

所有页面功能均基于 /api/* 下的 JSON REST 接口实现，本身就是开放 API。未来会补充更详细的接口文档与认证机制（Session / Token），便于第三方工具或脚本接入。
